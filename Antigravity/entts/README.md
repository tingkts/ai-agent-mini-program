# TTS 文字轉語音工具 (Text-to-Speech)

本工具採用微軟神經網路高音質語音引擎 (`edge-tts`)，免費且無須任何 API Key。支援**圖形化視窗介面 (GUI)** 以及 **命令列腳本 (CLI)**。

---

## 🖥️ GUI 視窗工具使用方式

### 啟動方式
1. **直接在檔案總管雙擊**：`啟動TTS工具.bat`
2. **或在終端機執行**：
   ```bash
   python tts_gui.py
   ```

### 視窗功能說明
- **貼上文字框**：可自由貼上大段長文，支援「一鍵貼上剪貼簿」、「清空」、或「開啟 txt 檔」，並有即時字數統計。
- **發音角色選擇**：
  - 支援美式英文 (Jenny / Guy / Aria)、英式英文 (Sonia / Ryan)、澳洲英文 (Natasha)。
  - 支援台灣繁體中文 (曉臻 / 雲哲)、香港粵語、日語、韓語等。
  - 預設「**自動偵測語系**」，若貼上英文會自動使用美式自然英文發音。
- **核取選項 (Options)**：
  - ☑ **自動依輸入文字命名檔名**：預設存為文字前段內容（例如 `Hello_World.mp3`），若文字過長會**自動截短**；若未勾選或文字為空，預設固定為 `text.mp3`。
  - ☑ **轉換完成後開啟檔案資料夾**：生成完畢後自動彈出檔案總管並選取該檔案。
  - ☑ **轉換完成後立即播放音訊**：轉換完自動叫起預設播放器試聽。
- **儲存設定**：可自由修改預計檔名與變更存檔資料夾。
- **非同步多執行緒**：轉換大型長文時視窗完全不卡頓，附帶動態進度條。

---

## 💻 命令列 (CLI) 快速用法

```bash
# 英文自動偵測
python tts.py "Artificial Intelligence is transforming the way we work." -o english.mp3

# 指定台灣女聲或男聲
python tts.py "你好，歡迎使用語音合成" -v zh-tw-female -o taiwan.mp3

# 查詢支援的所有 320+ 種聲音
python tts.py --list-voices
```
