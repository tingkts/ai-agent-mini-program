## 【第一步：建立 Telegram 推播機器人（詳細步驟）】

推播需要取得兩個關鍵數值：
1. `TELEGRAM_BOT_TOKEN`：機器人的通訊身分證
2. `TELEGRAM_CHAT_ID`：您個人的 Telegram 使用者數字 ID

---

### 步驟 1-1：向官方 `@BotFather` 申請新機器人
1. 打開手機或電腦上的 **Telegram App**。
2. 點擊頂部的搜尋欄，搜尋：`@BotFather`（**注意：請認明名稱旁邊有「藍色勾勾」的官方認證標記**）。
3. 進入聊天室後，點擊底部的 **「START」** 按鈕（或手動輸入 `/start`）。
4. 在對話框輸入指令：
   ```text
   /newbot
   ```
5. **設定顯示暱稱（Name）**：BotFather 會問機器人的名字（可以輸入中文，例如 `遠東門診通知小幫手`）。
6. **設定帳號（Username）**：BotFather 接著會要求設定唯一帳號（必須以英文字母 `bot` 結尾，只能是英文、數字、底線）：
   - 例如輸入：`fepc_reg_alert_bot`
   - *（若畫面顯示 `Sorry, this username is already taken.`，代表已被他人使用過，換一個即可）*
7. 建立成功後，BotFather 會發送一段包含如下內容的訊息：
   > *Use this token to access the HTTP API:*
   > `7123456789:AAFn_abc123xyz456...`

   👉 這串長代碼就是您的 **`TELEGRAM_BOT_TOKEN`**，請先複製記下。

---

### 步驟 1-2：取得您個人的使用者 ID（Chat ID）
1. 在 Telegram 搜尋欄搜尋：`@userinfobot`。
2. 進入聊天室，點擊底部的 **「START」**（或傳送任何一個字）。
3. 機器人會立即回傳一張個人資訊卡：
   > *Id: 123456789*
   > *First: 您的名字*

   👉 其中 **`Id:`** 後面的純數字（通常是 9～10 位數，例如 `123456789`）就是您的 **`TELEGRAM_CHAT_ID`**。

---

### 步驟 1-3：★ 最關鍵的一步：啟動您的新機器人！
> [!IMPORTANT]
> Telegram 官方為防止垃圾廣告騷擾，規定**「機器人不能主動發訊息給從未對話過的陌生人」**。因此您必須先主動跟機器人講第一句話。

1. 在 Telegram 搜尋欄搜尋您在步驟 1-1 設定的機器人帳號（例如 `@fepc_reg_alert_bot`）。
2. 點進聊天室，點擊最底部的 **【START】** 按鈕（或發送 `/start`）。
3. 這樣就完成雙向授權，機器人之後才能把掛號通知傳到您的手機。

### 一、為什麼 GitHub Actions 沒有準確每 10 分鐘執行一次？

1. **GitHub 官方的延遲機制（佇列排隊）**：
   GitHub 官方文件明確說明：

### 問題一：如何查看 Git Remote Branch 的建立時間，並從最新開始排序？

在 Git 的底層設計中，分支本質上只是一個指向 Commit 的「指標」，因此 Git 查看分支時間通常有兩種需求情境：
1. **依「該分支最新活動/提交（Commit）的時間」由新到舊排序**（**最常用、99% 的情境適用**）。
2. **依「該分支最初建立（第一個 Commit）的時間」由新到舊排序**。

以下提供對應的指令：

#### 方法 A：依分支「最新活動時間」由新到舊排序（最推薦）

在您的專案終端機執行以下指令：

```bash
git for-each-ref --sort=-committerdate --format="%(committerdate:iso8601) | %(refname:short) | %(authorname)" refs/remotes/
```
- `--sort=-committerdate`：負號 `-` 代表**由新到舊**（最新建立/更新的排在最上面）。
- `%(committerdate:iso8601)`：顯示標準年月日時分秒。
- `%(refname:short)`：顯示遠端分支簡短名稱（如 `origin/feature-abc`）。
- `%(authorname)`：顯示該提交的作者。

**輸出範例：**
```text
2026-10-28 16:59:08 +0800 | origin/main | ting
2026-10-25 11:20:15 +0800 | origin/feature-login | alex
2026-09-15 14:02:30 +0800 | origin/dev | john
```

> 💡 **更簡短的寫法**：
> ```bash
> git branch -r --sort=-committerdate --format="%(committerdate:short) %(refname:short)"
> ```

---

#### 方法 B：找出分支「最早成立（從 main 分叉出來）」的時間
如果您想精確知道某個分支（例如 `origin/feature-test`）當初是哪一天被建立出來的，可以找出它與 `main` 的分叉點：
```bash
git log -1 --format="%cd" $(git merge-base origin/main origin/feature-test)
```

#### 方法 C：直接從 GitHub 網頁查看
1. 進入您在 GitHub 的專案頁面。
2. 點擊上方的 **Branches**（或網址直接加上 `/branches`，例如：`https://github.com/tingkts/ai-agent-mini-program/branches`）。
